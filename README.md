# Markstub

A free, open-source trademark search assistant.

Markstub is a single-file, static web tool built to make trademark searching
more approachable for first-time founders and small business owners who find
the USPTO's own search interface confusing. It doesn't replace due diligence
or legal advice — it's built to help you narrow a search from thousands of
results down to a manageable few, so you know what to look at more closely.

## What it does

- Helps you build exact-phrase USPTO trademark search queries and look up
  application status, without needing to already understand the USPTO's
  search syntax
- Narrows results down to a shortlist for your own further review — it is a
  starting point for due diligence, not a substitute for it
- Runs entirely in the browser — no account and no backend. The site uses
  Vercel Web Analytics for anonymous, cookieless page-view counts; nothing you
  type into the tool is sent anywhere

## Getting started

Open `index.html` in a browser, or visit the live version at:
[markstub.vercel.app](https://markstub.vercel.app/)
